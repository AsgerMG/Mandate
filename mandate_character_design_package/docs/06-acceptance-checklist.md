# 06 — Design and implementation acceptance checklist

## Brand fit
- [ ] Existing Mandate website palette and typography have been inspected and reused.
- [ ] No unverified replacement palette has been introduced.
- [ ] Existing navigation, page hierarchy and component language remain intact.

## Character identity
- [ ] Regina is recognisable as layered, ordered ceramic / mineral / glass architecture.
- [ ] Wincent is recognisable as interwoven, connected metal / glass architecture.
- [ ] Both are faceless and clearly non-human.
- [ ] Their silhouettes remain distinguishable in grayscale.
- [ ] Their visual weight and scale are equal in duo compositions.

## Neutrality
- [ ] No party, national, religious or ideological symbols.
- [ ] No resemblance to identifiable public figures.
- [ ] No human demographic stereotypes.
- [ ] No institutional endorsement is implied.

## Product accuracy
- [ ] Regina is associated with EU Rules intelligence.
- [ ] Wincent is associated with Public Capital intelligence.
- [ ] Copy does not imply drafting, filing, guaranteed funding, guaranteed eligibility, legal advice or lobbying outcomes.
- [ ] Source and date discipline is preserved where relevant.

## Web quality
- [ ] Images are optimized and responsive.
- [ ] Image dimensions / aspect ratios prevent layout shift.
- [ ] Alt text is appropriate.
- [ ] Reduced-motion preference is respected.
- [ ] Mobile presentation is deliberate.
- [ ] No unnecessary WebGL / 3D runtime dependency.
- [ ] Performance is checked on the actual site.
