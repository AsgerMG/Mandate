# Playbooks

What the advisor's agents are told, in files the owner can read and edit.

| file | read by | what it is |
|---|---|---|
| `method.md` | Mandate (the orchestrator), every mission | the advisory method: how any question is worked |
| `wincent.md` | Wincent (capital specialist) | persona, remit, how to use the capital tools |
| `regina.md` | Regina (policy specialist) | persona, remit, how to use the policy tools |
| `<job>.md` | Mandate, when the mission is that job | a job playbook: the practitioner's questions, routes, traps, stakeholders, tone, and what "great" looks like |

A job playbook is written from a structured interview with the owner (plan,
phase 0.5) and is the encoded instinct of a seasoned practitioner. The
orchestrator loads one with its `load_playbook` tool (the index it sees is the
first line of each job file), and the loaded playbook is also given to the
specialists it consults.

The site reads these through `web/lib/mandate/agent/playbooks.generated.ts`,
generated by `npx tsx scripts/emit_playbooks.ts` (run from `web/`). The vitest
`playbooks.test.ts` fails when the generated file and these files differ, so an
edit here cannot silently not ship.
